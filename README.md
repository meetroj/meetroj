## 🚀 About me

- 🔭 I mostly build **MERN-stack products** — React on the front, Express + MongoDB behind it.
- 📱 I also ship **React Native** apps (Android & iOS) with push notifications, geolocation, and offline-friendly data.
- 💳 I've wired up real production concerns: **payments (Razorpay)**, **media uploads (Cloudinary)**, **transactional email (Resend / Nodemailer)**, **auth (JWT + Google OAuth)**, and **scheduled jobs (node-cron)**.
- 🧩 I like owning the whole flow: API design → database modelling → UI → deploy.
- 💬 Ask me about **React, Node/Express, MongoDB, React Native, or Firebase**.
